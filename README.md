# Scholarship Management Portal

**Project ID:** JFS-56  
**Domain:** Education / Government

## Project Overview
The Scholarship Management Portal aims to digitize scholarship scheme publication, eligibility checking, student applications, document verification, scholarship sanction and disbursement tracking.

## User Roles
- Admin
- Student
- Institute Verifier
- Sanctioning Officer

## Main Modules
1. Authentication and Student Management
2. Scholarship Scheme Management
3. Applications and Documents
4. Verification and Sanction
5. Reports

## Current Implementation
An initial Java console prototype has been developed for Scholarship Scheme Management. It supports adding, displaying, searching, updating and deleting scholarship schemes using an ArrayList.

## Planned Technology Stack
- Java
- Spring Boot and REST APIs
- Spring Data JPA and Hibernate
- SQL database
- React, HTML, CSS and JavaScript
- Git and GitHub

## Future Enhancements
- Database integration
- Authentication and role-based access
- Eligibility checking
- Application and document management
- Verification, sanction and mock disbursement
- Scheme-wise reporting

## Current Limitation
The current Java prototype uses in-memory storage. Database persistence and the remaining modules are yet to be implemented.
