# Day 6 – Frontend Development

## Objective
To develop a basic frontend interface for the Scholarship Management Portal.

## Work Done
- Created a `Frontend` folder with `index.html`, `style.css`, and `script.js`.
- Designed a scholarship dashboard to display available scholarship schemes and their details.
- Used CSS to style scholarship cards, buttons, navigation, and dashboard sections.
- Used JavaScript to display sample scholarship data dynamically.
- Implemented an Apply button to create application entries and display their status.
- Created a basic `login.html` page with email, password, and role selection.

## Outcome
Developed a basic frontend prototype that displays scholarship schemes and simulates application submission. Backend integration and actual login authentication are yet to be implemented.
