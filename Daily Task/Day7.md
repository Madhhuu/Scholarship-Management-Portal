# Day 7 – Application Workflow and Architecture Design

## Objective
To understand the scholarship application workflow and prepare the proposed system architecture.

## Work Done
- Reviewed the scholarship dashboard and application submission workflow.
- Identified the four user roles: Student, Admin, Institute Verifier, and Sanctioning Officer.
- Reviewed the functional requirements for scholarship publication, application submission, verification, sanctioning, and status tracking.
- Prepared a proposed microservices architecture containing Auth Service, Scheme Service, and Application Service.
- Identified PostgreSQL as the planned database for storing application and scholarship information.
- Studied how REST APIs and OpenFeign can support communication between the frontend and backend services.

## Outcome
Documented the main application workflow and proposed architecture for future backend development. Microservices and database integration are planned for subsequent implementation.
